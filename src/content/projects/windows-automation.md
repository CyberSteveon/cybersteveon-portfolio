## From repetition to a script

After reinstalling Windows multiple times and repeatedly applying the same settings, I wanted a more consistent way to configure my own machines. This became a PowerShell tool for common setup tasks and privacy-focused configuration changes.

## What it does

- Automates common Windows setup tasks.
- Applies privacy and system configuration settings.
- Provides a repeatable baseline for personal installations.
- Leaves room for additional automation as my workflow evolves.

## What I learned

The project strengthened my PowerShell scripting skills and changed how I approach repetitive work. When I find myself applying the same configuration repeatedly, I look for an opportunity to make the process repeatable.

## Current status

The tool is an ongoing personal project. Its existing functionality provides a starting point for further improvements; it is not presented as an enterprise provisioning product or a quantified performance improvement.
