## A foundation in data

Atlas is my personal PostgreSQL database project. I am using it to develop practical experience with database design, relational modeling, and SQL, with Docker supporting the local development environment.

## Current focus

- Developing relational modeling and database design skills.
- Practicing SQL against PostgreSQL.
- Working with a container-based local development environment.

## Why it matters

Understanding how data is organized is an important part of my software engineering education. Atlas gives me a place to connect database concepts with hands-on practice.

## Current status

Atlas is actively being developed. A public repository, detailed schema walkthrough, and implementation examples are not yet included in this portfolio. The focus remains hands-on database learning.
